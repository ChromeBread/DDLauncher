Cara membaca tampilan

  • Bingkai / lampu abu-abu: berhenti / belum diatur
  • Hijau: berjalan (hak akses normal)
  • Oranye: berjalan (hak administrator)
  • Merah: diatur "Jalankan sebagai admin", tetapi berjalan dengan hak akses normal
  • Bingkai tile OBS: biru muda = tidak streaming / merah = sedang streaming / ungu = hanya merekam. Angka di tengah adalah jumlah data yang terkirim
  • Tile yang berkedip oranye: aplikasi berikutnya yang akan dijalankan oleh urutan peluncuran
  • Kanan atas tile: ADMIN / USER / STANDBY (berhenti) / NO PATH (belum diatur)
  • GROUP (berkolom; LINEAR belum tersedia): roda / ▲▼ memutar lingkaran. Aplikasi dengan kategori yang sama ditumpuk dan muncul ke samping saat kursor diarahkan. Shift+roda / tilt memutar isi satu baris

Mode tampilan (LINEAR / GROUP), batas mendatar / menurun, dan tindakan setelah urutan selesai (minimalkan / sembunyikan) bisa diubah di "Umum" pada pengaturan. Launcher yang disembunyikan bisa dikembalikan dari ikon tray.

Tampilan normal bisa dipilih antara "Hanya ikon (terbuka saat kursor diarahkan)" dan "Selalu terbuka" (di "Umum" pada pengaturan, atau dari menu klik kanan di area kosong launcher). Dalam mode D&D dan selama urutan peluncuran, launcher tetap terbuka.

Ukuran bisa diubah dengan Ctrl+roda mouse di atas launcher, atau dengan "Ukuran" di pengaturan.

Klik kiri ikon = jalankan (tidak melakukan apa-apa jika sudah berjalan) / klik kanan = pilih hak akses lalu jalankan.
Klik kanan area kosong launcher untuk membuka menu (posisi, urutan, pengaturan, keluar).

Keuntungan menjalankan OBS sebagai administrator

  • OBS bisa menaikkan prioritas GPU-nya sendiri, sehingga "rendering lag / encoding lag" lebih jarang muncul saat game membebani GPU.
  • Game Capture / Window Capture bisa menangkap game dan aplikasi yang berjalan sebagai administrator.
  • Beberapa game dengan anti-cheat hanya bisa ditangkap jika OBS berjalan sebagai administrator.

Kekurangan

  • Drag & drop dari Explorer tidak bisa lagi. (lihat di bawah)
  • Konfirmasi UAC muncul setiap kali dijalankan. Jika dijalankan saat startup, UAC muncul tepat setelah login.
  • Browser source, plugin, dan script di dalam OBS juga berjalan sebagai administrator. Berhati-hatilah terutama dengan plugin dari sumber yang tidak jelas dan URL browser source.
  • Tool dengan hak akses normal (AutoHotkey, software makro, dll.) tidak bisa mengirim input tombol atau operasi jendela ke OBS. Untuk hotkey, disarankan mengontrol lewat obs-websocket (Stream Deck, dll.).
  • File yang dibuka dan program yang dijalankan dari OBS juga berjalan sebagai administrator.

Mengapa drag & drop tidak bisa

Windows punya mekanisme bernama UIPI (User Interface Privilege Isolation) yang memblokir pesan jendela dari proses berhak rendah ke proses berhak tinggi. Explorer berjalan dengan hak normal dan OBS sebagai administrator, jadi operasi drop (OLE D&D / WM_DROPFILES) tidak sampai ke OBS dan kursor berubah menjadi tanda "dilarang". Menjalankan Explorer sebagai administrator tidak disarankan.

DDLauncher berjalan dengan hak akses normal, sehingga bisa menerima drop dari Explorer. Path file yang diterima dikirim ke OBS lewat obs-websocket (koneksi localhost). Koneksi jaringan tidak terkena UIPI, jadi tetap sampai ke OBS dengan aman meskipun hak aksesnya berbeda.

※ Jika launcher sendiri dijalankan sebagai administrator, D&D tidak bisa dipakai karena alasan yang sama (header menampilkan ⚠ADMIN).

Panduan untuk streamer

  • Game → Game Capture (mode "Capture specific window" disarankan. "Capture any fullscreen application" kadang menangkap sesuatu selain game yang dituju dengan Alt+Tab)
  • Game Capture hitam → ganti ke Window Capture (metode: Windows 10 (1903 ke atas)). Jika masih gagal, gunakan Display Capture
  • Comment viewer, browser, tool → Window Capture (metode Windows 10 (1903 ke atas) stabil)
  • Display Capture adalah pilihan terakhir. Seluruh desktop ikut terlihat, termasuk notifikasi, Discord, dan input kata sandi, jadi waspadai kecelakaan saat siaran
  • Game Capture tidak menampilkan jendela yang menimpa, jadi aman mengoperasikan aplikasi lain saat streaming. Window Capture juga sama, tetapi perhatikan bahwa gambar berhenti jika target diminimalkan (aplikasi yang dijalankan dengan "Mulai diminimalkan" di launcher ini sebaiknya dikembalikan dulu sebelum ditangkap)

Layar hitam dan hal lain yang perlu diperhatikan

  • Laptop (dua GPU): Display Capture menjadi hitam jika OBS dan aplikasi yang ditangkap berjalan di GPU berbeda. Samakan GPU OBS di "Pengaturan grafis" Windows.
  • Video DRM di browser (layanan streaming, dll.) menjadi hitam karena proteksi. Mematikan akselerasi hardware browser kadang membuatnya terlihat, tetapi perhatikan juga masalah hak cipta.
  • Aplikasi yang berjalan sebagai administrator menjadi hitam / tidak muncul di daftar jika ditangkap dengan Window Capture dari OBS berhak normal. → Salah satu alasan utama menjalankan OBS sebagai administrator.
  • Jika Game Capture hitam: aktifkan "Use anti-cheat compatibility hook", atau ganti ke Display Capture.
  • Jendela yang dijalankan dalam keadaan diminimalkan kadang tidak terlihat di Window Capture. Kembalikan ke ukuran normal sekali setelah dijalankan.

Urutan peluncuran

  • Menjalankan aplikasi sesuai urutan di pengaturan, masing-masing "jeda detik setelah aplikasi sebelumnya dijalankan". Aplikasi yang sudah berjalan tidak dijalankan dua kali.
  • Taruh DAW dan VB-Audio (VoiceMeeter, dll.) di akhir dengan jeda lebih panjang agar tidak berebut perangkat audio.
  • "Mulai diminimalkan" hanya meminta jendela ditampilkan dalam keadaan diminimalkan. Beberapa aplikasi mengabaikannya (untuk OBS, argumen --minimize-to-tray lebih andal).
  • "Nama exe proses" dipakai untuk memeriksa apakah aplikasi berjalan. Untuk aplikasi tipe launcher (yang setelah dijalankan berpindah ke exe lain), isi dengan nama exe utamanya.

Memilih monitor

  • Jika dipilih di kolom "Pindah ke monitor", launcher menunggu jendela muncul hingga 30 detik lalu memindahkannya ke monitor itu (posisi relatif dan status minimal / maksimal tetap dijaga).
  • Aplikasi yang dijalankan sebagai administrator tidak bisa dipindahkan (UIPI mencegah launcher berhak normal mengontrolnya). OBS dan aplikasi sejenis mengingat posisi terakhirnya, jadi cukup letakkan sekali dengan tangan dan lain kali akan muncul di sana.
  • Aplikasi yang menampilkan splash screen tepat setelah dijalankan kadang jendela utamanya tidak ikut pindah.

Port

  • Daftarkan port yang dipakai OBS WebSocket (4455), comment viewer, dan tool integrasi untuk memeriksa statusnya.
  • Kosong (abu-abu) / Dipakai (hijau: dipakai proses yang diharapkan) / Bentrok (merah: dipakai proses tak terduga, atau terdaftar dua kali).
  • Isi nama exe (misalnya obs64.exe) di "Proses yang diharapkan" agar tampil bentrok jika aplikasi lain memakai port yang sama.
  • "Bebaskan" menutup proses yang memakai port itu. Proses yang berjalan sebagai administrator tidak bisa ditutup. Jika bentrok, biasanya cukup ubah nomor port di pengaturan salah satu aplikasi.

Pengaturan di OBS

Di OBS, aktifkan melalui menu "Tools" → "WebSocket Server Settings", lalu masukkan port dan kata sandinya di pengaturan DDLauncher bagian "Umum / OBS".
